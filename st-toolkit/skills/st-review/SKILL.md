# ST 评审清单

按以下顺序逐项检查,每项给出 通过/问题(行号+原因+建议):

1. **语义交集**:是否落在 matiec ∩ S7-SCL 交集(定位/非定位变量分块声明、CTU 复位参数是 R、不用 STEP 作变量名、边沿触发顺序控制、不单 TON 自复位振荡)?
2. **死输出**:每个声明的 %Q 输出是否都有赋值驱动来源?
3. **边界**:阈值 `<` vs `<=` 是否明确;负数/0/上界各落哪个分支;CASE 都有 ELSE?
4. **互斥/优先级**:急停/停止类信号是否最先判断且压倒后续;互斥输出真的互斥?
5. **时序**:跨周期记忆有正确复位条件;每周期重算的在程序体开头显式赋初值?
6. **可读性**:块注释(用途/接口/假设)齐全;魔法数有命名常量或注释;命名风格一致?

输出格式:逐项结论 + 一个「必修/建议」分级的问题清单。
